Previously, we implemented a pretraining loop to train a small GPT-2 model on a limited dataset. While this approach demonstrates the fundamentals of network optimization, training a model from scratch to achieve high proficiency requires extensive computational resources. We now bypass this bottleneck by loading external, pretrained weights directly into our model architecture.

Key Takeaways

  • Loading external pretrained weights circumvents the extensive computational time and resources required to train a model from scratch.
  • Model configurations, such as the context length and layer biases, must strictly match the structural assumptions of the pretrained weights to load them successfully.
  • Verifying the generated output text immediately after loading the weights confirms structural and mathematical compatibility between the loaded state dictionary and the local architecture.

Loading pretrained weights from OpenAI

We retrieve the state dictionary for OpenAI's 124-million-parameter GPT-2 model from a public repository. We download the .pth weight file and save it to the local disk.

import os
import requests

file_name = "gpt2-small-124M.pth"
url = f"https://huggingface.co/rasbt/gpt2-from-scratch-pytorch/resolve/main/{file_name}"

if not os.path.exists(file_name):
    response = requests.get(url, timeout=60)
    response.raise_for_status()
    with open(file_name, "wb") as f:
        f.write(response.content)
    print(f"Downloaded to {file_name}")

We create a revised configuration dictionary to align with the imported weights. Earlier, we used a context length of 256 tokens to optimize local memory usage. The original GPT-2 model was trained with a context length of 1024, so we must restore this dimension.

Additionally, the original OpenAI implementation utilized bias vectors in the multi-head attention module’s linear layers to execute the query, key, and value matrix projections. While bias vectors are largely omitted in contemporary architectures because they increase parameter counts without tangibly improving performance, they are structurally embedded in these specific pretrained weights. Consequently, we must enable these bias vectors to maintain dimensional consistency.

import torch
# Assume GPT_CONFIG_124M and GPTModel are defined in previous chapters

NEW_CONFIG = GPT_CONFIG_124M.copy()
NEW_CONFIG.update({"context_length": 1024})
NEW_CONFIG.update({"qkv_bias": True})

gpt = GPTModel(NEW_CONFIG)
gpt.load_state_dict(torch.load(file_name, weights_only=True))
gpt.eval()

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
gpt.to(device)

IMPORTANT

The OpenAI weights map to specific variable names within the state dictionary. To load the weights successfully without KeyErrors, the multi-head attention module instance within the `TransformerBlock` class must be explicitly named `self.att`. If the module was previously named `self.attn`, the class definition and `forward` pass must be updated, and the classes must be re-instantiated prior to loading the weights.

We evaluate the structural integrity of the loaded model by prompting it to generate text. If the weights map correctly to the mathematical operations, the model will output coherent English prose.

# Assume generate, text_to_token_ids, token_ids_to_text, and tokenizer are defined
torch.manual_seed(123)

token_ids = generate(
    model=gpt,
    idx=text_to_token_ids("Every effort moves you", tokenizer).to(device),
    max_new_tokens=25,
    context_size=NEW_CONFIG["context_length"],
    top_k=50,
    temperature=1.5
)

print("Output text:\n", token_ids_to_text(token_ids, tokenizer))

# Output
Output text:
 Every effort moves you as far as the hand can go until the end of your turn unless something happens

This would remove you from a battle

The model produces coherent text, confirming that the parameter matrices were loaded into the exact structural positions required by the architecture. A subtle dimensional mismatch or naming error during the state dictionary mapping would cause the forward pass to fail entirely or output severe noise. With the pretrained baseline established, the architecture is now prepared for task-specific fine-tuning.
