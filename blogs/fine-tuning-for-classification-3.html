We define the optimization loop to fine-tune the pretrained model and improve its spam classification accuracy over the dataset.

Key Takeaways

  • The classification training loop monitors explicit accuracy alongside cross-entropy loss to provide interpretable metrics of model performance during optimization.
  • Plotting training and validation metrics over successive epochs is critical for identifying model convergence and diagnosing potential overfitting.
  • For inference, novel text inputs must undergo identical tokenization, truncation, and padding procedures as the training dataset prior to passing through the classification head.

Executing the training loop

The training function mirrors the structure used for pretraining the language model. The primary distinctions are that we track the cumulative number of training examples processed rather than the number of tokens, and we compute the explicit classification accuracy after each epoch instead of generating a text sample.

# Assume evaluate_model, calc_loss_batch, and calc_accuracy_loader are defined
def train_classifier_simple(
    model, train_loader, val_loader, optimizer, device, num_epochs, eval_freq, eval_iter
):
    train_losses, val_losses, train_accs, val_accs = [], [], [], []
    examples_seen, global_step = 0, -1

    for epoch in range(num_epochs):
        model.train() 
        for input_batch, target_batch in train_loader:
            optimizer.zero_grad() 
            loss = calc_loss_batch(
                input_batch, target_batch, model, device
            )
            loss.backward()
            optimizer.step()
            examples_seen += input_batch.shape[0]
            global_step += 1

            if global_step % eval_freq == 0:
                train_loss, val_loss = evaluate_model(
                    model, train_loader, val_loader, device, eval_iter
                )
                train_losses.append(train_loss)
                val_losses.append(val_loss)
                print(
                    f"Ep {epoch+1} (Step {global_step:06d}): "
                    f"Train loss {train_loss:.3f}, "
                    f"Val loss {val_loss:.3f}"
                )

        train_accuracy = calc_accuracy_loader(
            train_loader, model, device, num_batches=eval_iter
        )
        val_accuracy = calc_accuracy_loader(
            val_loader, model, device, num_batches=eval_iter
        )
        print(f"Training accuracy: {train_accuracy*100:.2f}% | ", end="")
        print(f"Validation accuracy: {val_accuracy*100:.2f}%")

        train_accs.append(train_accuracy)
        val_accs.append(val_accuracy)

    return train_losses, val_losses, train_accs, val_accs, examples_seen

def evaluate_model(model, train_loader, val_loader, device, eval_iter):
    model.eval()
    with torch.no_grad():
        train_loss = calc_loss_loader(
            train_loader, model, device, num_batches=eval_iter
        )
        val_loss = calc_loss_loader(
            val_loader, model, device, num_batches=eval_iter
        )
    model.train()
    return train_loss, val_loss

We initialize the optimizer, define the epoch count, and execute the training process.

import time
import torch

start_time = time.time()
torch.manual_seed(123)

optimizer = torch.optim.AdamW(model.parameters(), lr=5e-5, weight_decay=0.1)
num_epochs = 5

train_losses, val_losses, train_accs, val_accs, examples_seen = \
    train_classifier_simple(
        model, train_loader, val_loader, optimizer, device,
        num_epochs=num_epochs, eval_freq=50, eval_iter=5
    )

end_time = time.time()
execution_time_minutes = (end_time - start_time) / 60
print(f"Training completed in {execution_time_minutes:.2f} minutes.")

Plotting the results

We utilize Matplotlib to visualize the cross-entropy loss across the training and validation sets over the computed epochs.

import matplotlib.pyplot as plt

def plot_values(
    epochs_seen, examples_seen, train_values, val_values, label="loss"
):
    fig, ax1 = plt.subplots(figsize=(5, 3))

    ax1.plot(epochs_seen, train_values, label=f"Training {label}")
    ax1.plot(
        epochs_seen, val_values, linestyle="-.", label=f"Validation {label}"
    )
    ax1.set_xlabel("Epochs")
    ax1.set_ylabel(label.capitalize())
    ax1.legend()

    ax2 = ax1.twiny()
    ax2.plot(examples_seen, train_values, alpha=0)
    ax2.set_xlabel("Examples seen")
    fig.tight_layout()
    plt.savefig(f"{label}-plot.pdf")
    plt.show()

epochs_tensor = torch.linspace(0, num_epochs, len(train_losses))
examples_seen_tensor = torch.linspace(0, examples_seen, len(train_losses))

plot_values(epochs_tensor, examples_seen_tensor, train_losses, val_losses)

The model’s training and validation loss over the five training epochs. Both the training loss, represented by the solid line, and the validation loss, represented by the dashed line, sharply decline in the first epoch and gradually stabilize toward the fifth epoch. This pattern indicates structural learning without severe overfitting.

We apply the same function to plot the classification accuracies over the training duration.

epochs_tensor = torch.linspace(0, num_epochs, len(train_accs))
examples_seen_tensor = torch.linspace(0, examples_seen, len(train_accs))

plot_values(
    epochs_tensor, examples_seen_tensor, train_accs, val_accs, label="accuracy"
)

The model’s training and validation accuracy over the five epochs, demonstrating a rapid initial increase in accuracy followed by asymptotic stabilization.

The training loop outputs limited metrics evaluated on a small subset of batches (e.g., eval_iter=5). We compute the definitive performance metrics for the training, validation, and test sets across the entire dataset by running the accuracy function without defining a batch limit.

train_accuracy = calc_accuracy_loader(train_loader, model, device)
val_accuracy = calc_accuracy_loader(val_loader, model, device)
test_accuracy = calc_accuracy_loader(test_loader, model, device)

print(f"Training accuracy: {train_accuracy*100:.2f}%")
print(f"Validation accuracy: {val_accuracy*100:.2f}%")
print(f"Test accuracy: {test_accuracy*100:.2f}%")

Using the LLM as a spam classifier

We formulate a function to execute inference on novel text. The classify_review function replicates the data preprocessing steps implemented in the dataset class. It converts raw text into token IDs, enforces a maximum length, and applies uniform padding. The network then processes the formatted tensor, and we extract the predicted integer label via the argmax function on the final token logits.

def classify_review(
    text, model, tokenizer, device, max_length=None, pad_token_id=50256
):
    model.eval()
    input_ids = tokenizer.encode(text)
    supported_context_length = model.pos_emb.weight.shape[1]

    input_ids = input_ids[:min(max_length, supported_context_length)]
    input_ids += [pad_token_id] * (max_length - len(input_ids))

    input_tensor = torch.tensor(
        input_ids, device=device
    ).unsqueeze(0)

    with torch.no_grad():
        logits = model(input_tensor)[:, -1, :]

    predicted_label = torch.argmax(logits, dim=-1).item()
    return "spam" if predicted_label == 1 else "not spam"

We evaluate the classify_review function on two independent sample strings to verify the predictive logic.

text_1 = (
    "You are a winner you have been specially"
    " selected to receive $1000 cash or a $2000 award."
)
print(classify_review(
    text_1, model, tokenizer, device, max_length=train_dataset.max_length

text_2 = (

We persist the optimized model state dictionary to disk, allowing future inference without requiring a retraining phase.

torch.save(model.state_dict(), "review_classifier.pth")

This saved dictionary can be loaded into an identical, uninitialized architecture using standard PyTorch loading mechanisms.

model_state_dict = torch.load("review_classifier.pth", map_location=device)
model.load_state_dict(model_state_dict)
