With the dataset batched and prepared, we initialize the pretrained architecture to adapt the network for text classification.

Key Takeaways

  • Pretrained language models without specific instruction fine-tuning cannot execute zero-shot classification tasks reliably, necessitating structural fine-tuning.
  • Modifying an architecture for classification involves freezing the majority of the network, replacing the final language modeling head with a discrete classification layer, and unfreezing the terminal transformer block to optimize for the new objective.
  • Cross-entropy loss serves as a differentiable proxy to maximize classification accuracy. For sequence classification, this loss is computed explicitly on the final token of the input sequence.

Base model initialization and testing

We initialize the pretrained model using the standard architectural configuration defined during the pretraining phase.

import torch
# Assume GPTModel and file_name are defined in previous chapters

GPT_CONFIG = {
    "vocab_size": 50257,    # Vocabulary size
    "context_length": 1024, # Context length
    "emb_dim": 768,         # Embedding dimension
    "n_heads": 12,          # Number of attention heads
    "n_layers": 12,         # Number of transformer blocks
    "drop_rate": 0.1,       # Dropout rate
    "qkv_bias": True        # Query-Key-Value bias
}

model = GPTModel(GPT_CONFIG)
model.load_state_dict(torch.load(file_name, weights_only=True))
model.eval()

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)

We evaluate whether the base pretrained model can execute zero-shot classification by prompting it with explicit instructions to classify a text string.

# Assume generate_text_simple, text_to_token_ids, and tokenizer are defined
text = (
    "Is the following text 'spam'? Answer with 'yes' or 'no':"
    " 'You are a winner you have been specially"
    " selected to receive $1000 cash or a $2000 award.'"
)

token_ids = generate_text_simple(
    model=model,
    idx=text_to_token_ids(text, tokenizer),
    max_new_tokens=23,
    context_size=GPT_CONFIG["context_length"]
)
print(token_ids_to_text(token_ids, tokenizer))

# Output

The following text 'spam'? Answer with 'yes' or 'no': 'You are a winner

The output demonstrates that the base model fails to follow the classification instruction. It simply attempts to autocomplete the prompt by echoing the input pattern. This validates the necessity of supervised fine-tuning.

Adding a classification head

To modify the pretrained language model for classification, we replace the original output layer. The standard language modeling head maps the hidden representation to a vocabulary of 50,257 tokens. We substitute this with a minimal linear layer that maps to two distinct classes: 0 ("not spam") and 1 ("spam").

We first freeze the entire model structure by disabling gradient tracking on all parameters. We then instantiate and assign the new classification head.

for param in model.parameters():
    param.requires_grad = False

torch.manual_seed(123)
num_classes = 2

model.out_head = torch.nn.Linear(
    in_features=GPT_CONFIG["emb_dim"],
    out_features=num_classes
)

By default, newly instantiated PyTorch modules have requires_grad=True. Consequently, the out_head is currently the only trainable layer in the network. While training only the final linear layer (often called linear probing) is technically sufficient, unfreezing the terminal transformer block significantly improves predictive performance by allowing deeper feature adaptation.

We explicitly unfreeze the parameters of the final transformer block and the subsequent layer normalization module.

for param in model.trf_blocks[-1].parameters():
    param.requires_grad = True

for param in model.final_norm.parameters():
    param.requires_grad = True

Calculating the classification loss and accuracy

During language generation, we determine the predicted token by applying a softmax transformation to the output logits and selecting the maximum value via argmax. We apply the identical principle for sequence classification, but we extract the logits exclusively from the final token position in the sequence.

The model outputs corresponding to the final sequence token are converted into probability scores for each input text. Class labels are derived by identifying the index position of the highest probability score. The untrained model predicts labels incorrectly as the linear head is randomly initialized.

inputs = tokenizer.encode("Do you have time")
inputs = torch.tensor(inputs).unsqueeze(0).to(device)

with torch.no_grad():
    outputs = model(inputs)

probas = torch.softmax(outputs[:, -1, :], dim=-1)
label = torch.argmax(probas)
print("Class label:", label.item())

# Output
Class label: 1

The application of the softmax function is strictly optional for classification inference, as the maximum raw logit consistently corresponds to the highest probability score.

logits = outputs[:, -1, :]
label = torch.argmax(logits)
print("Class label:", label.item())

# Output
Class label: 1

To quantify the overall classification accuracy across an entire dataset, we implement a comprehensive evaluation function, calc_accuracy_loader.

def calc_accuracy_loader(data_loader, model, device, num_batches=None):
    model.eval()
    correct_predictions, num_examples = 0, 0

    if num_batches is None:
        num_batches = len(data_loader)
    else:
        num_batches = min(num_batches, len(data_loader))

    for i, (input_batch, target_batch) in enumerate(data_loader):
        if i < num_batches:
            input_batch = input_batch.to(device)
            target_batch = target_batch.to(device)

            with torch.no_grad():
                logits = model(input_batch)[:, -1, :]

            predicted_labels = torch.argmax(logits, dim=-1)
            num_examples += predicted_labels.shape[0]
            correct_predictions += ((predicted_labels == target_batch).sum().item())
        else:
            break

    return correct_predictions / num_examples

We apply this function to evaluate the baseline classification accuracy of the randomly initialized head across the training, validation, and test splits.

# Assume train_loader, val_loader, and test_loader are defined
torch.manual_seed(123)

train_accuracy = calc_accuracy_loader(
    train_loader, model, device, num_batches=10
)
val_accuracy = calc_accuracy_loader(
    val_loader, model, device, num_batches=10
)
test_accuracy = calc_accuracy_loader(
    test_loader, model, device, num_batches=10
)

print(f"Training accuracy: {train_accuracy*100:.2f}%")
print(f"Validation accuracy: {val_accuracy*100:.2f}%")
print(f"Test accuracy: {test_accuracy*100:.2f}%")

# Output
Training accuracy: 46.25%
Validation accuracy: 45.00%
Test accuracy: 48.75%

The baseline accuracy hovers near 50 percent, reflecting the performance of a random binary classifier. To optimize the network and improve these metrics, we must define a differentiable loss function. Classification accuracy itself is non-differentiable due to the discrete step function of the argmax operation. We therefore utilize cross-entropy loss as a differentiable proxy objective.

We define calc_loss_loader to compute this metric, explicitly focusing on the logits of the final sequence token (model(input_batch)[:, -1, :]).

# Assume calc_loss_batch is defined to calculate cross_entropy on the final token
def calc_loss_loader(data_loader, model, device, num_batches=None):
    total_loss = 0.
    if len(data_loader) == 0:
        return float("nan")
    elif num_batches is None:
        num_batches = len(data_loader)
    else:
        num_batches = min(num_batches, len(data_loader))

    for i, (input_batch, target_batch) in enumerate(data_loader):
        if i < num_batches:
            loss = calc_loss_batch(
                input_batch, target_batch, model, device
            )
            total_loss += loss.item()
        else:
            break

    return total_loss / num_batches

We evaluate the baseline cross-entropy loss before optimization.

with torch.no_grad():
    train_loss = calc_loss_loader(
        train_loader, model, device, num_batches=5
    )
    val_loss = calc_loss_loader(
        val_loader, model, device, num_batches=5
    )
    test_loss = calc_loss_loader(
        test_loader, model, device, num_batches=5
    )

print(f"Training loss: {train_loss:.3f}")
print(f"Validation loss: {val_loss:.3f}")
print(f"Test loss: {test_loss:.3f}")

# Output
Training loss: 2.453
Validation loss: 2.525
Test loss: 2.413

With the architecture modified and the loss function mathematically formulated, the network is ready for the optimization loop to systematically minimize the training loss.
