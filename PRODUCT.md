# Product

## Register

brand

## Platform

web

## Users
Developers, engineering students, and open-source contributors looking for technical explanations, code structures, and project design walkthroughs.

## Product Purpose
A personal portfolio and technical blog displaying projects and writeups on Large Language Models, Agentic AI, and scratch-built neural networks. Success is measured by reader engagement, clear knowledge-transfer, and code contributions.

## Positioning
An educational and practical log of building state-of-the-art AI systems and LLMs from scratch.

## Conversion & proof
- Primary and secondary CTA: Primary is reading/learning from the blogs; secondary is exploring and starring the GitHub repositories.
- The line a visitor remembers after 10 seconds: A developer documenting the step-by-step assembly of complex LLMs and agent systems.
- Belief ladder:
  1. The author has deep technical, hands-on experience building neural networks and agents.
  2. The code and blog explanations are correct, thoroughly illustrated, and practical.
  3. Readers can learn and adapt these patterns for their own builds.
- Proof on hand: Links to five key GitHub projects (EyeTalk, revive-v2, Aegis, Crack_detection, arbitrum) and detailed code walkthroughs.

## Brand Personality
Technical, clean, minimalist, and editorial (inspired by premium developer blogs like Stripe Developer Blog).

## Anti-references
SaaS-cream warm-neutral layouts, overstimulating glassmorphism, flat or generic template grids.

## Design Principles
1. **Show the Code**: Make code snippets, data flow, and diagrams the center of the UI.
2. **Editorial Simplicity**: Keep margins wide, layouts clean, and visual elements aligned.
3. **No Fluff**: Focus on factual explanations without marketing jargon.

## Accessibility & Inclusion
Standard WCAG AA compliance with light/dark contrast and prefers-reduced-motion support.
